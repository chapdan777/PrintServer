# Руководство: Централизованный Driverless Print Server (CUPS IPP Everywhere)

## 1. Архитектура и как это работает

Внедрена современная бездрайверная архитектура печати на базе открытого стандарта **IPP Everywhere (Internet Printing Protocol)** и **DNS-SD (mDNS)**:

```
[ Windows 10/11 Клиенты ]
       │
       │ (1) Автообнаружение mDNS (UDP 5353)
       │ (2) Передача заданий печати: PDF / IPP (TCP 631)
       ▼
[ Docker: printserver-cups (192.168.2.141) ]
       │
       │ (3) Передача заданий на физические МФУ по IPP
       ▼
┌──────────────────────────────────────┐
│  HP LaserJet Pro MFP M428 (.241)     │
│  HP LaserJet Pro MFP M428 (.244)     │
└──────────────────────────────────────┘
```

### Ключевые преимущества:
1. **Zero-Touch (Без установки драйверов)**:
   - Windows 10/11 использует свой собственный встроенный драйвер **`Microsoft IPP Class Driver`** (Type 4, in-box).
   - Не требуется скачивать пакеты HP UPD, запускать инсталляторы или иметь права локального администратора для подключения принтера.
2. **Иммунитет к уязвимостям PrintNightmare**:
   - Samba Spoolss и RPC Point-and-Print полностью исключены из тракта печати.
   - Нет ошибок `0x80070bcb` («Пакет драйвера принтера заблокирован политикой»).
3. **Полная функциональность оборудования**:
   - Поддерживается **двусторонняя печать (Duplex)**.
   - Поддерживается выбор лотков (**Лоток 1, Лоток 2, Автовыбор**).
   - Поддерживается печать документов из любых офисных и бухгалтерских программ.
4. **Безопасность и изоляция**:
   - Клиенты не обращаются к принтерам напрямую в обход сервера — трафик централизован и логируется в CUPS (`/var/log/cups/page_log`).

## 3. Инструкция по подключению для пользователей Windows

Подключение выполняется буквально в 3 клика:

1. Нажмите меню **Пуск** ➔ откройте **Параметры** (значок шестерёнки) ➔ выберите **Устройства** ➔ **Принтеры и сканеры**.
2. В верхней части окна нажмите **`+ Добавить принтер или сканер`**.
3. Подождите 5–10 секунд, пока Windows выполнит поиск в сети.
4. В списке найденных устройств выберите нужный принтер:
   - **`HP LaserJet Pro MFP M428fdn @ servvm`** (принтер .241)
   - **`HP LaserJet Pro MFP M428fdw @ servvm`** (принтер .244)
5. Нажмите кнопку **`Добавить устройство`**.
6. Windows свяжет принтер и назначит драйвер `Microsoft IPP Class Driver`. Через 10 секунд принтер готов к работе.

## 4. Проверка и управление для администратора (PowerShell)

### Проверка установленных очередей на клиенте:
```powershell
Get-Printer | Where-Object { $_.Name -like "*servvm*" } | Select-Object Name, DriverName, PortName
```
*Ожидаемый драйвер:* `Microsoft IPP Class Driver`.  
*Ожидаемый порт:* `WSD-...` (автоматический порт сопряжения mDNS).

### Проверка поддержки дуплекса и лотков:
```powershell
Get-PrintConfiguration -PrinterName "HP LaserJet Pro MFP M428fdn @ servvm"
```

### Удаление старых/неактуальных очередей (при необходимости):
```powershell
# Просмотр всех принтеров
Get-Printer | Select-Object Name

# Удаление устаревшего принтера
Remove-Printer -Name "Старое_Имя_Принтера"
```

## 5. Добавление новых принтеров и драйверов через Web GUI (CUPS)

Веб-панель управления сервером позволяет добавлять любые новые и старые принтеры через удобный графический интерфейс без работы в терминале.

### Данные для входа в панель администратора:
- **Адрес панели:** [http://192.168.2.141:631/admin](http://192.168.2.141:631/admin)
- **Логин:** `admin`
- **Пароль:** `admin`

---

### Пошаговая инструкция по добавлению принтера через Web GUI:

#### Шаг 1: Авторизация и запуск мастера
1. Откройте в браузере [http://192.168.2.141:631/admin](http://192.168.2.141:631/admin).
2. Нажмите кнопку **«Add Printer»** (Добавить принтер).
3. При запросе браузера введите логин `admin` и пароль `admin`.

#### Шаг 2: Выбор протокола подключения
В списке доступных протоколов выберите нужный в зависимости от принтера:
- **Для современных сетевых МФУ/принтеров (с 2013 г.):**  
  Выберите **Internet Printing Protocol (ipp)** или **IPP Everywhere** ➔ нажмите *Continue*.  
  *Пример адреса:* `ipp://192.168.2.245/ipp/print`
- **Для старых сетевых принтеров (HP, Kyocera, Xerox и т.д.):**  
  Выберите **AppSocket/HP JetDirect** ➔ нажмите *Continue*.  
  *Пример адреса:* `socket://192.168.2.245:9100`
- **Для локальных USB-принтеров:**  
  Выберите появившийся принтер в разделе *Local Printers (USB)*.

#### Шаг 3: Имя и сетевой доступ (ВАЖНО!)
1. **Name (Имя):** краткое системное имя без пробелов (например, `HP_M404_245` или `Kyocera_P2040`).
2. **Description (Описание):** понятное человеческое название (например, `HP LaserJet Pro M404 [Кабинет 5]`).
3. **Location (Расположение):** физический адрес или номер кабинета.
4. ⚠️ **ОБЯЗАТЕЛЬНО установите флажок:** **`☑ Sharing: Share This Printer`** *(Разрешить совместный доступ)*.  
   *Без этой галочки принтер не будет анонсироваться по сети Windows-клиентам!*
5. Нажмите *Continue*.

#### Шаг 4: Выбор или загрузка драйвера
- **Вариант А (Автоматический / IPP Everywhere):**  
  Если принтер современный, выберите пункт **IPP Everywhere** или марку из списка и модель.
- **Вариант Б (Выбор из базы драйверов Linux):**  
  Выберите производителя (например, *HP*, *Kyocera*), нажмите *Continue*, затем выберите точную модель принтера из списка.
- **Вариант В (Загрузка внешнего файла драйвера PPD):**  
  Если для старого или специфического принтера скачан файл описания драйвера (`.ppd`), нажмите кнопку **«Обзор...» / «Choose File»** в блоке *«Or Provide a PPD File»*, выберите `.ppd` файл и нажмите **Add Printer**.

#### Шаг 5: Настройки печати по умолчанию
1. Установите размер бумаги: **Media Size: A4**.
2. Установите двустороннюю печать (при наличии модуля): **2-Sided Printing: Long-Edge (портретная ориентация)**.
3. Нажмите кнопку **«Set Default Options»**.

#### Результат:
Принтер мгновенно сохраняется в постоянной конфигурации сервера, регистрируется в службе mDNS/Avahi и сразу появляется в Windows в окне «Добавить принтер или сканер» у всех сотрудников сети.

## 6. Статус Production на сервере `192.168.2.141`

Серверная часть полностью переведена в Production и проверена:

1. **Автозапуск (Persistence)**:
   - Контейнер `printserver-cups` имеет директиву `restart: unless-stopped`.
   - Проверено полным холодным перезапуском хоста (`reboot`): все службы поднимаются автоматически за 25–30 секунд.
2. **Сохранение конфигураций (Volumes)**:
   - Очереди и параметры печати хранятся в томе `cups-config` (`printers.conf`).
   - Буфер очереди печати сохраняется в томе `cups-spool`.
3. **Оптимизация mDNS (Avahi)**:
   - Служба Avahi жестко привязана к физическому интерфейсу `eth0` (`allow-interfaces=eth0`).
   - Отключен мультикаст IPv6 (`use-ipv6=no`), исключены внутренние Docker-мосты — анонсы стабильны и не создают коллизий.
4. **Web GUI Администрирование**:
   - Настроен доступ к `/admin` из локальной сети `192.168.2.0/24`.
   - Создана учетная запись администратора `admin:admin`.

### Полезные команды на сервере `192.168.2.141`:
```bash
# Проверить статус службы CUPS
docker exec printserver-cups lpstat -r

# Просмотреть очереди и их состояние
docker exec printserver-cups lpstat -p -d

# Просмотреть лог напечатанных страниц
docker exec printserver-cups tail -n 20 /var/log/cups/page_log

# Проверить публикацию принтеров в сети LAN
docker exec printserver-cups avahi-browse -rt _ipp._tcp -t
```
