# Руководство системного администратора: Централизованный Driverless Print Server

## 1. Архитектура решения и принцип работы

В корпоративной сети `192.168.2.0/24` развернута централизованная архитектура печати на базе открытого стандарта **IPP Everywhere (Internet Printing Protocol)**, утвержденного консорциумом Printer Working Group (PWG), и протокола автообнаружения **DNS-SD (mDNS)**.

### Схема тракта печати:

```mermaid

        W10 --> W10_Driver
    end

    subgraph Server["Сервер приложений (Debian 13, 192.168.2.141)"]
```

### Как это функционирует:
1. **Обнаружение (Discovery)**: Внутри контейнера `printserver-cups` служба `avahi-daemon` транслирует mDNS-анонсы (`_ipp._tcp`, `_cups._sub._ipp._tcp`) строго через физический интерфейс `eth0` в сеть `192.168.2.0/24`. Клиенты Windows видят доступные сетевые принтеры в окне «Добавить принтер или сканер» без предварительной настройки.
2. **Драйвер на клиенте (Zero-Touch)**: Windows сопоставляет mDNS-анонс принтера со своим штатным универсальным драйвером **`Microsoft IPP Class Driver` (Type 4)**. Драйвер уже встроен в состав Windows (in-box Driver Store). Клиенту не требуются права администратора, не нужно ничего скачивать с интернета или файловых серверов.
3. **Согласование возможностей (Attributes)**: При подключении Windows опрашивает CUPS по протоколу IPP (порт 631) и моментально считывает все аппаратные характеристики:
   - Поддержка дуплекса (`sides-supported: one-sided, two-sided-long-edge, two-sided-short-edge`);
   - Доступные лотки подачи бумаги (`media-source-supported: auto, tray-1, tray-2`);
   - Поддерживаемые форматы носителей (`media-supported: A4, A5, Letter, Legal`).
4. **Рендеринг и отправка**: Windows генерирует задание в стандартном формате **PDF 1.7** или PWG-Raster и передает его на CUPS `http://192.168.2.141:631/printers/<очередь>`.
5. **Доставка на МФУ**: Сервер CUPS пересылает задание на физическое МФУ HP по нативному протоколу IPP (`ipp://192.168.2.xxx/ipp/print`). Прямого сетевого обращения клиентов к принтерам в обход сервера нет.

## 2. Обоснование отказа от штатных драйверов HP (HP UPD / Point-and-Print / Samba Spoolss)

Ранее предпринятая попытка развертывания классической схемы печати Windows на базе **Samba Spoolss + HP Universal Print Driver (HP UPD)** показала фундаментальную непригодность для современного продакшена по следующим причинам:

### 1. Блокировка безопасности Microsoft PrintNightmare (`0x80070bcb`)
После волны критических уязвимостей (CVE-2021-34527 / PrintNightmare) корпорация Microsoft внедрила жесткие механизмы защиты (обновления KB5005010, KB5005652 и последующие накопительные пакеты).
- Windows блокирует автоматическую установку любых неподписанных или сторонних драйверов принтеров по сети с сервера печати (`ERROR_PRINTER_DRIVER_PACKAGE_BLOCKED`, код ошибки `0x80070bcb`).
- Для успешной установки требуется, чтобы сервер печати отдавал клиенту доверенный **Driver Package** через расширение протокола **MS-PAR (Package Point-and-Print)**.

### 2. Ограничения Samba Spoolss
Текущие версии Samba (включая 4.22) не поддерживают архитектуру Package Point-and-Print:
- Вызов метода RPC `_spoolss_GetPrinterDriverPackagePath` возвращает `WERR_NOT_SUPPORTED`.
- Samba способна распространять только устаревшие монолитные драйверы **Type 3 (User Mode)** через классический протокол MS-RPRN. Windows 10 LTSC 1809+ считает такую передачу небезопасной и прерывает установку.
- Назначение драйверов нового поколения (Type 4 / v4) через Samba SPOOLSS невозможно: команда `enumdrivers 8` возвращает статус `WERR_INVALID_LEVEL`, так как структуры Level 8 не поддерживаются демоном `smbd`.

### 3. Проблема разрядности архитектур (x86 vs x64)
В существующей инфраструктуре эксплуатируются рабочие станции с 32-битной ОС (Windows 10 Enterprise LTSC 2019 x86, например ПК `ALINA`) и 64-битные системы.
- Для классического Point-and-Print администратору требовалось держать на сервере два раздельных комплекта драйверов: `Windows x64` и `Windows NT x86`.
- Малейшее расхождение версий библиотек HP UPD между x86 и x64 в сетевой папке `print$` приводило к сбоям `0x80070705` («Указанный драйвер принтера не найден в системе»).

### 4. Нестабильность и «тяжеловесность» вендорного ПО HP
- Пакеты HP Universal Print Driver (UPD) PCL6 / PostScript содержат десятки мегабайт сторонних DLL, фоновые службы двунаправленного опроса (SNMP / Bi-directional communication), компоненты сбора аналитики и интеграции с HP Cloud.
- Сбои в этих компонентах приводят к зависанию службы диспетчера очереди печати Windows (`spoolsv.exe`), утечкам дескрипторов и падению офисных программ при открытии диалога печати.
- Принтеры HP регулярно «теряли» статус дуплексного модуля при временных задержках SNMP-ответа.

### Сравнительная таблица подходов:

| Критерий | Старая схема (Samba + HP UPD) | Целевая схема (CUPS IPP Everywhere) |
|---|---|---|
| **Установка на клиенте** | Ручная установка INF + локальный порт `\\server\queue` (костыль) | Zero-Touch в 3 клика через mDNS |
| **Права локального админа** | Требуются на каждом рабочем месте | **Не требуются** (драйвер уже в ОС) |
| **Ошибки Point-and-Print** | Постоянные блокировки `0x80070bcb` | Исключены архитектурно (Samba не используется) |
| **Поддержка разрядностей** | Нужны отдельные сборки под x86 и x64 | Единый драйвер Microsoft для всех CPU и ОС |
| **Двусторонняя печать** | Зависит от SNMP Bi-Di агента HP | Нативно определяется через IPP-атрибуты |
| **Надежность Spooler** | Риск краха `spoolsv.exe` от DLL вендора | 100% стабильность (только штатные компоненты Microsoft) |

## 3. Инструкция по добавлению новых принтеров через Web GUI CUPS

Сервер CUPS оснащен веб-интерфейсом администрирования, позволяющим подключить любой принтер полностью мышкой без терминала.

### Реквизиты доступа к Web GUI:
- **URL панели управления:** [http://192.168.2.141:631/admin](http://192.168.2.141:631/admin)
- **Имя пользователя:** `admin`
- **Пароль:** `admin`
*(Права доступа ограничены локальной подсетью `192.168.2.0/24`).*

---

### Пошаговый сценарий добавления принтера:

#### Шаг 1: Авторизация
1. Откройте в браузере [http://192.168.2.141:631/admin](http://192.168.2.141:631/admin).
2. Нажмите кнопку **«Add Printer»** в разделе *Printers*.
3. Во всплывающем окне браузера укажите логин `admin` и пароль `admin`.

#### Шаг 2: Выбор протокола подключения
В зависимости от типа подключаемого устройства выберите переключатель:

1. **Для современных сетевых МФУ/принтеров (выпуск от 2013 г., поддержка Mopria / AirPrint / IPP):**
   - Выберите: **`Internet Printing Protocol (ipp)`** или **`IPP Everywhere`**.
   - Нажмите *Continue*.
   - В поле **Connection** введите:
     ```
     ipp://192.168.2.XXX/ipp/print
     ```
2. **Для старых сетевых принтеров (HP LaserJet 1320, 2015, 2055, сетевые Kyocera, Xerox и т.д.):**
   - Выберите: **`AppSocket/HP JetDirect`**.
   - Нажмите *Continue*.
   - В поле **Connection** введите:
     ```
     socket://192.168.2.XXX:9100
     ```
3. **Для локальных принтеров, подключенных к серверу по USB:**
   - Выберите принтер в группе **`Local Printers`** (он определится автоматически, например `HP LaserJet 1020 (USB)`).
   - Нажмите *Continue*.

#### Шаг 3: Назначение имени и ОБЩЕГО ДОСТУПА (КРИТИЧЕСКИ ВАЖНО)
Заполните форму параметров очереди:
1. **Name (Имя):** краткий идентификатор без пробелов и спецсимволов, латиницей (например: `HP_M404_245` или `Kyocera_P2040_Buh`).
2. **Description (Описание):** понятное для сотрудников отображаемое имя (например: `HP LaserJet Pro M404 [Кабинет 5]`).
3. **Location (Расположение):** физическое местоположение (например: `Бухгалтерия, 2 этаж`).
4. ⚠️ **ОБЯЗАТЕЛЬНО установите флажок:**
   ```
   [✓] Sharing: Share This Printer
   ```
   *Если флажок не установлен, принтер будет скрыт и служба Avahi не анонсирует его в Windows!*
5. Нажмите *Continue*.

#### Шаг 4: Выбор или загрузка драйвера
- **Вариант А (Автоматический / Современный принтер):**  
  В списке *Make* выберите **Generic**, нажмите *Continue*, затем выберите **IPP Everywhere** (или модель принтера из списка) ➔ нажмите **Add Printer**.
- **Вариант Б (Старый принтер из встроенной базы Linux):**  
  В списке *Make* выберите марку (например, *HP*, *Kyocera*, *Brother*), нажмите *Continue*, выберите точную модель с суффиксом `(en)` или `(recommended)` ➔ нажмите **Add Printer**.
- **Вариант В (Загрузка файла PPD для редких моделей):**  
  Если для принтера скачан файл описания `модель.ppd`, в блоке **«Or Provide a PPD File»** нажмите кнопку **«Обзор / Choose File»**, укажите путь к файлу `.ppd` на вашем компьютере ➔ нажмите **Add Printer**.

#### Шаг 5: Конфигурация параметров по умолчанию
Откроется экран настроек принтера по умолчанию:
1. **Media Size (Формат бумаги):** выберите **`A4`** (по умолчанию часто стоит американский Letter).
2. **2-Sided Printing (Дуплекс):** если в принтере есть модуль двусторонней печати, выберите **`Long-Edge (Portrait)`**.
3. **Starting Tray (Лоток по умолчанию):** выберите `Auto Select` или `Tray 2`.
4. Нажмите кнопку **«Set Default Options»**.

#### Итог:
Новый принтер немедленно сохранен в конфигурации сервера `printers.conf` и автоматически анонсирован демоном `avahi-daemon`. В течение 5–10 секунд он становится доступен для установки на всех клиентских компьютерах под управлением Windows.

## 4. Инструкция по подключению на клиентских ПК Windows 10/11

Подключение выполняется сотрудником самостоятельно за 20 секунд:

1. Нажмите клавишу **Windows** (или кнопку «Пуск») ➔ откройте **«Параметры»** (значок шестерёнки).
2. Перейдите в раздел **«Устройства»** ➔ слева выберите вкладку **«Принтеры и сканеры»**.
3. Нажмите кнопку **`+ Добавить принтер или сканер`**.
4. Windows выполнит сканирование сети (зеленый индикатор поиска).
5. В списке найденных устройств выберите нужный принтер:
   - **`HP LaserJet Pro MFP M428fdn @ servvm`** (МФУ .241)
   - **`HP LaserJet Pro MFP M428fdw @ servvm`** (МФУ .244)
   - Или новый добавленный вами принтер.
6. Нажмите кнопку **`Добавить устройство`**.
7. Подождите 10 секунд до появления надписи *«Готово»*. Принтер готов к печати, включая двустороннюю печать и выбор лотков.

## 5. Диагностика и обслуживание для системного администратора

### Полезные команды PowerShell на клиентах Windows:
```powershell
# Список подключенных очередей servvm и их драйверов
Get-Printer | Where-Object { $_.Name -like "*servvm*" } | Select-Object Name, DriverName, PortName

# Проверка параметров дуплекса
Get-PrintConfiguration -PrinterName "HP LaserJet Pro MFP M428fdn @ servvm"

# Удаление устаревшей или ненужной очереди
Remove-Printer -Name "Старый_Принтер"
```

### Полезные команды на сервере `192.168.2.141`:
```bash
# Проверка планировщика CUPS
docker exec printserver-cups lpstat -r

# Просмотр статуса очередей
docker exec printserver-cups lpstat -p -d

# Просмотр сетевых анонсов Avahi в LAN
docker exec printserver-cups avahi-browse -rt _ipp._tcp -t

# Лог отправленных заданий и страниц
docker exec printserver-cups tail -n 30 /var/log/cups/page_log
```
